# 🔐 Security Policy

This project is under active development. Security updates are applied to the latest version.

| Version        | Supported |
| -------------- | --------- |
| Latest         | ✅ Yes     |
| Older versions | ❌ No      |

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### 📧 Contact

* Email: [your-email@example.com](mailto:chetansonigara01@gmail.com)
* GitHub: Open a private security advisory (preferred)

---

## 🔒 Guidelines for Reporting

Please include the following details:

* Description of the vulnerability
* Steps to reproduce
* Potential impact
* Suggested fix (if available)

---

## ⚠️ Do NOT

* Do not publicly disclose vulnerabilities before reporting
* Do not exploit vulnerabilities beyond proof-of-concept
* Do not access data that is not yours

---

## 🛡️ Security Considerations

This project involves:

* Machine learning models
* Simulation environments (CARLA)
* Large datasets

### ⚠️ Risks to consider:

* Malicious model files (.pth)
* Untrusted datasets
* Dependency vulnerabilities

---

## 🔍 Best Practices

* Always verify model files before use
* Use trusted datasets and sources
* Keep dependencies updated
* Run code in isolated environments (virtualenv / Docker)

---

## 📦 Dependencies

We rely on open-source libraries such as:

* PyTorch
* OpenCV
* NumPy

Please ensure all dependencies are up to date to avoid known vulnerabilities.

---

## 🧠 AI-Specific Security Notes

* Avoid using unverified pretrained weights
* Validate input data before inference
* Monitor model behavior for unexpected outputs

---

## ⏱️ Response Time

We aim to respond within:

* **48–72 hours** for initial acknowledgment
* Further updates will follow after review

---

## 🤝 Responsible Disclosure

We appreciate responsible disclosure and will:

* Investigate all valid reports
* Fix confirmed issues
* Credit contributors (if desired)
