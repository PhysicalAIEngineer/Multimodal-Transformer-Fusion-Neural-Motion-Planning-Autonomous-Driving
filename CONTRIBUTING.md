# 🤝 Contributing to Multimodal Transformer Autonomous Driving

Thank you for your interest in contributing! 🚀
This project focuses on **end-to-end autonomous driving using multimodal sensor fusion (RGB + LiDAR), transformer-based perception, and neural motion planning**.

We welcome contributions from researchers, engineers, and students.

---

## 📌 How to Contribute

### 1. 🍴 Fork the Repository

Click the **Fork** button on the top right of this repository.

---

### 2. 📥 Clone Your Fork

```bash
git clone https://github.com/<your-username>/Multimodal-Transformer-Fusion-Neural-Motion-Planning-Autonomous-Driving.git
cd Multimodal-Transformer-Fusion-Neural-Motion-Planning-Autonomous-Driving
```

---

### 3. 🌿 Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

Examples:

* `feature/add-bev-visualization`
* `feature/improve-fusion-module`
* `bugfix/lidar-processing-error`

---

### 4. 🛠️ Make Your Changes

* Follow the project structure
* Write clean and readable code
* Add comments where necessary
* Ensure compatibility with existing modules

---

### 5. 🧪 Test Your Changes

Before submitting:

* Run the pipeline end-to-end
* Check for runtime errors
* Validate outputs (visualizations, predictions)

---

### 6. 💾 Commit Your Changes

```bash
git add .
git commit -m "Add: short description of your changes"
```

Use meaningful commit messages:

* `Add: BEV visualization module`
* `Fix: LiDAR coordinate transformation bug`
* `Improve: Transformer fusion efficiency`

---

### 7. 📤 Push to Your Fork

```bash
git push origin feature/your-feature-name
```

---

### 8. 🔁 Create a Pull Request (PR)

* Go to your fork on GitHub
* Click **Compare & Pull Request**
* Provide a clear description:

  * What you changed
  * Why it is useful
  * Any relevant results or screenshots

---

## 📏 Code Guidelines

* Follow **PEP8 (Python style guide)**
* Use meaningful variable names
* Keep functions modular
* Avoid unnecessary complexity

---

## 📂 Project Structure Guidelines

* Do not break existing modules
* Add new features in separate files when possible
* Keep configs centralized

---

## ⚠️ Large Files & Models

* Do NOT upload large `.pth` files directly
* Use:

  * Git LFS
  * OR external links (Google Drive / HuggingFace)

---

## 🐛 Reporting Issues

If you find a bug:

* Open an **Issue**
* Include:

  * Description
  * Steps to reproduce
  * Expected vs actual behavior

---

## 💡 Feature Requests

We welcome ideas!
Open an issue with:

* Problem statement
* Proposed solution

---

## 📜 Code of Conduct

* Be respectful and professional
* Provide constructive feedback
* Collaborate openly
